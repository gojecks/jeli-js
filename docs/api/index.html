API reference

API

Covers the real, current runtime API - grounded in each package's index.d.ts. Internal/advanced classes (renderer, DI plumbing) are listed for completeness but most application code won't touch them directly.

@jeli/core - Decorators & options

Element(options: ElementOptions)

decorator

Declares a component: selector, template, DI, and its input/output surface.

selector: string;              // must contain a hyphen
template?: string;             // plain string, not a template literal
templateUrl?: string;
style?: string;
styleUrl?: string;
asNative?: boolean;            // compile to a real customElements.define()
useShadowDom?: boolean;        // only meaningful with asNative
props?: string[];              // "name" | "name:Type" | "name:Type=default"
events?: string[];             // "eventName: handlerCall($event)"
DI?: any[];
resolve?: any[];
viewChild?: string[];          // "field=#refId" | "field:Type=#refId"
contentChild?: string[];       // same syntax - must resolve to QueryList
contentChildren?: string[];

Element itself is not declared as a global TypeScript function - it collides with the DOM's own global Element interface. Type the options object directly instead.

Directive(options: DirectiveOptions)

decorator

Behavior attached to an existing element - no template of its own. Same option shape as Element minus template/style fields.

Service(options?: ServiceOptions)

decorator

An injectable, singleton-by-default class.

DI?: any[];
resolve?: any[];
registerAs?: any;

Provider(options: ProviderOptions)

decorator

Registers an alternative implementation against an existing DI token. Extends ServiceOptions.

useExisting?: any;
useClass?: Function;
useValue?: any;
useFactory?: Function;

Pipe(options?: PipeOptions)

decorator

A value | pipeName:arg template transform. Extends ServiceOptions, plus selector?: string.

jModule(options: JModuleOptions)

decorator
services?: (Function | { name: any; useClass?; factory?; DI?; value? })[];
requiredModules?: Function[];
selectors?: (Function | { useExisting: Function; selector: string })[];
exports?: any[];
rootElement?: Function;   // only meaningful on the module passed to bootStrapApplication()

Dependency injection

class ProviderToken<T>

class

A DI token for non-class values (config, primitives). new ProviderToken(tokenName, multiple?, provide?).

Inject<T>(dep, localInjector?): T

function

Resolves a single dependency descriptor - the same resolution logic constructor injection uses internally.

AutoWire(constructorFN, localInjector?, callback?)

function

Constructs constructorFN, resolving its declared ctors.DI and injecting them positionally.

staticInjectionToken

const

The set of runtime-only tokens injectable without a registered service: ElementRef, TemplateRef, ContentData, changeDetector, ViewRef, ParentRef, VALIDATORS, QueryList, HostRef, HTMLElement, ContentHostRef, HostElement. Request these with a trailing ? in a DI array (see the guide).

Bootstrap & change detection

bootStrapApplication(moduleToBootStrap): Promise<void>

function

Compiles and mounts a jModule's rootElement at its selector in the document.

ChangeDetector(): void

function

Triggers a full, app-wide change-detection sweep from the bootstrapped root.

changeDetector (per-component, injected)

instance

Injected via DI: ['changeDetector?']. Methods:

detectChanges()Normal cascade trigger (no-op if this component is in manual mode).
onlySelf()Re-checks this component and its children, not its parent.
manualCheck()Bypasses the manual-mode gate entirely - for a manual-mode component's own explicit self-trigger.
markAsManual()Opts this component out of the automatic cascade permanently (until manualCheck() is called explicitly).
markAsChecked() / markAsUnChecked() / markAsOnce()Lower-level state control.
statusCurrent detector state (getter).

enableHydrationMode() / disableHydrationMode()

function

Opt-in flag: when enabled immediately before bootStrapApplication(), the root and its structural-directive-free descendants adopt existing server-rendered DOM nodes instead of recreating them. Structural-directive-containing subtrees fall back to a full remount.

INITIALIZERS / APP_BOOTSTRAP / APP_BASE_HREF / APP_ASSET_URL

ProviderToken

INITIALIZERS resolve (as promises) before the root component mounts; APP_BOOTSTRAP callbacks fire right after it does.

Lifecycle

See the didInit/viewDidLoad/viewDidDestroy hooks in the guide. Internally these are driven by the LifeCycle class (component/lifecycle.js), which also exposes an opt-in promise-tracking mode (enableLifecyclePromiseTracking()/drainLifecyclePromises()) used by server-render tooling to await async didInit() work before serializing.

Reactive primitives

A small, hand-rolled reactive layer - not RxJS-compatible, but shaped similarly.

class Subject<T>

class

next(value), subscribe(success, error?, completed?) → unsubscribe function. @jeli/http's HttpService returns one of these per request.

rxWatch(source, changeDetector, onNext?): () => void

function

Subscribes to a Subject-shaped source; on every emission calls onNext(value) then changeDetector.manualCheck(). The standard pairing with markAsManual() - see the guide.

debounce(func, wait, immediate?)

function

Classic debounce helper; rxDebounceTime(timeout, immediate?) adapts it to the (value, listener) operator shape below.

rxWhile / rxUntilChanged

function

Operator-shaped helpers: (value, next) => next(passed). rxUntilChanged() gates on isequal against the previous value.

rxEvents(target, eventNames): () => void

function

Registers one or more DOM event listeners on target; returns a cleanup function that removes them.

class EventEmitter / class Observer / class Promise2

class

Lower-level primitives Subject and the rest of the rx layer are built from.

Animation

animate(element, styles, speed?, callback?, easing?)

function

Animates numeric style properties over speed milliseconds. styles is either a {prop: targetValue} map or a (delta) => void callback for full control. easing is one of linear / quadratic / swing (default) / circ / back / bounce / elastic.

Shorthand helpers: animate.hide, animate.show, animate.fadeIn, animate.fadeOut, animate.slideUp, animate.slideDown, animate.toggleSlide - each (element, speed?, callback?).

createAnimation(config: AnimationConfig): AnimationController

function

A declarative, named-state config built on top of animate(). Scoped to unitless numeric CSS properties (opacity, zIndex, ...).

const fade = createAnimation({
    states: { void: { opacity: 0 }, visible: { opacity: 1 } },
    transitions: {
        'void => visible': { duration: 200, easing: 'swing' }
    },
    defaults: { duration: 300, easing: 'swing' }
});

fade.trigger(element, 'visible');       // Promise<void>
fade.currentState(element);             // 'visible' | 'void' | ...
trigger(element, toName, fromName?)Transitions to the named state; fromName defaults to whichever state was last reached (or 'void'). Resolves once the transition completes.
currentState(element)The state name last reached via trigger().

Devtools

global.jeli.devtools - attached automatically when @jeli/core loads, callable from any browser/Node console.

getComponentTree(elementRef?): DevtoolsComponentTreeNode | null

function

A plain snapshot of the live element tree from the bootstrapped root (or a given elementRef): { refId, tagName, isComponent, componentInstance?, children } per node.

inspectElement(nativeNode): ElementRef | TextNodeRef | null

function

Finds the live wrapper object behind a native DOM node.

inspectComponent(target): DevtoolsComponentInfo | null

function

target is a native DOM node or a component instance. Returns { selector, instance, refId, changeDetectorStatus, dependencies } - each dependency described from its declared ctors.DI entry, with a resolved singleton instance where one exists.

enableSingletonTracking() / disableSingletonTracking() / getSingletonInstances()

function

Opt-in (off, zero overhead by default) log of every singleton service/component instantiated via Inject() since tracking was enabled. getSingletonInstances() returns null when tracking isn't on, otherwise {name, instance}[] in creation order.

global.jeli.debug(nativeNode)

function

Returns the component/template context bound to a native DOM node - the original, minimal debug hook, still available alongside devtools.

Renderer & internals

These back the compiled template output (core.ViewParser.jit(...) calls jeli-cli emits) - most application code interacts with them indirectly, through templates and lifecycle hooks, not directly.

SymbolRole
ViewParserInterprets a compiled template AST into real DOM (the JIT renderer).
ElementRef / TextNodeRefWrapper objects around a native element/text node - hold binding subscriptions, DI, and the parent/child tree used by devtools.
ComponentRefPer-component registry entry: change detector, observables, parent/child refIds.
TemplateRef / ViewRefNamed-template (#refId) resolution and light-DOM content projection.
ElementCompilerDrives a component's compile-then-mount sequence.
EventHandlerDOM event delegation/dispatch for compiled @event bindings.
AttributeAppender / ElementClassList / ElementStyleAttribute/class/style binding appliers.
QueryList<T>An Array subclass backing viewChild/contentChild query results, with an onChanges subject.
createCustomElement / CompileNativeElementThe Web Components bridge behind asNative.
ComponentFactoryResolverProgrammatically instantiates and mounts a component factory.
IterableProfiler*for's diff engine - a doubly-linked-list-backed keyed diff (create/move/delete) between renders.

Utilities

class LazyLoader

class

Dynamic script/CSS loading with caching and dedupe: LazyLoader.js(obj, callback?), .css(obj) (both via <script>/<link> tag injection), and LazyLoader.resolveModule(filePaths, callback?) - a real dynamic-import()-based alternative sharing the same cache.

errorBuilder(error, logLevel?, stack?)

function

The framework's internal error/warning logger - also usable from application code.

MediaQueryEvent(breakPoints, callback): () => void

function

Subscribes to a set of pixel breakpoints via matchMedia; returns an unsubscribe function.

@jeli/common

Registered via CommonModule in a jModule's requiredModules. Backs the structural-directive attribute syntax and the built-in pipes.

DirectiveSelector / usage
ForDirective*for="item of collection; idx=index" / @for (...) { }
IfDirective*if="cond; else as X" / @if (...) { } @else { }
SwitchDirective / SwitchCaseDirective / SwitchDefaultDirective{:switch} / *switchCase / *switchDefault, or @switch/@case/@switchDefault
ClassDirective{jClass}="{active: isActive}" (or a plain string) - a conditional class-list add/remove directive

The native class attribute can also be bound directly ({class}="{active: isActive}") via the generic property-binding path (core, not this package) - either form works; ClassDirective/jClass specifically diffs against the previously-applied class instead of overwriting the attribute wholesale.

PipeUsage
capitalize${name | capitalize}
currency${amount | currency}
json${obj | json}
lowercase / uppercase${str | lowercase}
number${n | number}
orderBy${list | orderBy:'field'}
filter${list | filter:{field: value}} - object-shaped predicate
whereFilter${list | whereFilter:"id === 'a'"} - string query expression
reverse${list | reverse}
sizeToUnit${bytes | sizeToUnit}

@jeli/common/datetime additionally provides a dateTime/timeAgo pipe set and a <jx-calendar> element - import DateTimeModule separately.

@jeli/form

Registered via FormModule. A FormGroup/FormControl-shaped model - naming is the reverse of what it sounds like coming from Angular: FormControlService is the group, FormFieldControlService is the single field. Both extend a shared FormControlAbstract (value, valid/invalid, enabled/disabled, touched/untouched, error, valueChanges/statusChanged event emitters, setValue/patchValue/reset/enable/disable/setValidators/getError/hasError).

FormFieldControlService

service

A single control's value/validity state - jeli's equivalent of Angular's FormControl. Bound directly via {fieldControl}="control", or created internally by model/formField.

FormControlService

service

A named group of FormFieldControlService/nested FormControlService instances - jeli's equivalent of Angular's FormGroup. getField('a.b') resolves nested groups by dot-path; addField/removeField/patchValue/setValue/forEachField/allTouched()/getAllValues().

const form = new FormControlService({
    name: { value: '', validators: { required: true, minlength: 2 } },
    email: { value: '', validators: { required: true, emailvalidation: true } }
});

FormRepeaterService

service

An indexed array of controls - Angular's FormArray equivalent. Each entry is a FormFieldControlService, or a full FormControlService group when constructed with a field config.

Directives

directive
modelPlain two-way binding via its own internal FormFieldControlService - {:model}="prop".
formControlBinds a FormControlService (group) to a container - {formControl}="form".
formControlNameReferences a named field on the nearest ancestor formControl - formControlName="email".
formFieldDeclares and auto-registers a field on the nearest ancestor formControl, by name - formField="email".
fieldControlBinds a standalone FormFieldControlService directly, no group - {fieldControl}="emailControl".

Value accessors

directive

Bridge a native input type's own change-event shape to a uniform value: DefaultEventBinder (text/textarea), CheckboxEventBinder, RadioEventBinder (+ RadioEventContainer), SelectEventBinder (+ OptionDirective), NumberEventBinder, RangeEventBinder - matched automatically to the element/input type via the VALUE_ACCESSOR multi-token, nothing to configure.

Validators

function

Two sources, combinable: native HTML5 attributes (required, pattern, minlength, maxlength on the element itself, picked up automatically), or an explicit config object passed at construction / via setValidators({...}), keys matched case-insensitively against the built-in stack: required, requiredtrue, minlength, maxlength, pattern, emailvalidation, minnumber, maxnumber, domainvalidation, mediumpasswordstrength, strongpasswordstrength, isempty, boolean - or a plain (value) => boolean function, or an async key for an async validator.

FormValidatorService(callback, validators?, isDeep?) runs a validator set directly; customFormValidator(name, fn, override?) registers a new named validator globally.

@jeli/http

Registered via HttpModule (optionally HttpCSRFModule for cookie-based CSRF headers).

HttpService

service

get/post/put/delete/patch-style methods, each returning a Subject (not a Promise) that emits once with the parsed response, or errors via its error channel.

useFetchTransport() / useXhrTransport()

function

Switches the underlying transport globally. XHR is the default; useFetchTransport() swaps in a fetch()-backed adapter (FetchXHRAdapter) with the same public surface - no upload-progress or unknown-length-download-progress support.

setXhrFactory(factory)

function

Overrides how a raw XMLHttpRequest-shaped object gets constructed - the seam useFetchTransport() itself is built on; useful for tests.

HTTP_INTERCEPTORS

ProviderToken

A multi-token - register a class here (via a module's services) to intercept every request/response.

HttpRequestError / HttpResponse

class

Shapes delivered on the error/success channel respectively.

@jeli/router

Registered via RouterModule in requiredModules; routes are registered imperatively with RouterModule.setRoutes(...), typically from the route module's own constructor.

RouterModule

module
class RouterModule {
    static setRoutes(routes: RouteDefinition | RouteDefinition[]): void;
    static lazyLoad(routes: RouteDefinition | RouteDefinition[]): void;
}

interface RouteDefinition {
    name?: string;
    url?: string;
    parent?: string;
    component?: any;
    loadModule?: () => Promise<any>;   // lazy-loaded route module
    children?: RouteDefinition[];
    data?: Record<string, any>;
    views?: Record<string, any>;        // named outlets, e.g. { '@content': SomeElement }
    targetView?: string;
    abstract?: boolean;
    fallback?: boolean;                 // matched when nothing else does
    isIntent?: boolean;
    transition?: number;
}
jModule({ requiredModules: [RouterModule] })
export class AppRouteModule {
    constructor() {
        RouterModule.setRoutes([
            { name: 'home', url: '/', component: HomeElement, fallback: true },
            { name: 'user', url: '/users/:id', component: UserElement }
        ]);
    }
}

ROUTE_LOCATION_STRATEGY

ProviderToken

Selects the navigation strategy - HashStrategyService (hash-based) or PathStrategyService (History API), both extending AbstractStrategy. Defaults to hash-based.

LocationService

service

Reads the current path/search params. Accepts an injected per-request location context (rather than the ambient global window.location) - the seam server-side rendering uses to render a specific route per request.

ROUTE_INTERCEPTOR

ProviderToken

A multi-token for route guards - register a class shaped { resolve(routeInstance: RouteInterceptorInstance, next, reject) }; call next() to let the navigation proceed, routeInstance.redirect(routeName) or reject() to stop it. jeli has no per-route canActivate - a registered guard runs on every navigation and decides per-route itself (see routeInstance.name/.path).

getRoute / getHref / getRequiredRoute / parseUrl

function

Route-table lookups and URL construction, usable outside of a template (e.g. programmatic navigation).

GoFn

directive

Backs the :go="routeName" template directive for declarative navigation links.
