The framework that compiles your templates,
not just your components.

jeli is a decorator-based framework for building interactive web UIs - components, real dependency injection, a compiler-driven template language, and first-class TypeScript types, without a virtual DOM.

counter.element.js
import { CounterService } from './counter.service';

Element({
    selector: 'app-counter',
    // a plain string, not a JS template literal - jeli's own
    // compiler interprets ${ } inside it, not the JS engine
    template:
        '<button @click="decrement()">-</button>' +
        '<span>${count}</span>' +
        '<button @click="increment()">+</button>',
    DI: [CounterService]
})
export class CounterElement {
    constructor(counterService) {
        this.counterService = counterService;
        this.count = 0;
    }
    increment() { this.count = this.counterService.step(this.count, 1); }
    decrement() { this.count = this.counterService.step(this.count, -1); }
}
🧩

Decorator-based components

Element, Directive, Service, Provider, Pipe and jModule - a familiar, Angular-shaped mental model with constructor-injected dependencies.

⚙️

A real compiler

Templates are parsed and compiled ahead of time by jeli-cli - including an Angular-17-style @if/@for/@switch block syntax alongside the classic *if/*for attribute directives.

🚀

Compiled bindings

Opt in to buildOptions.compiledBindings and expression bindings compile down to real JS functions at build time instead of being interpreted at runtime.

🔌

Batteries included

First-party packages for structural directives & pipes (@jeli/common), reactive forms (@jeli/form), HTTP with interceptors (@jeli/http), and routing (@jeli/router).

🖥️

Server-side rendering

Render a real component tree to a string on the server, then hydrate it on the client by adopting existing DOM nodes instead of re-creating them from scratch.

🛠️

Typed & inspectable

Hand-authored .d.ts types ship with every package, and global.jeli.devtools gives you a component-tree walker and DI inspector from any console.
